# 🛒 Calculadora de Descontos - Loja Online

Script em Python desenvolvido para automatizar o cálculo de descontos progressivos em compras de um e-commerce, aplicando alíquotas baseadas no valor total adquirido.

---

## 📌 Regras de Negócio

O sistema avalia o valor informado na entrada e aplica o percentual de desconto correspondente:

| Valor da Compra (R$) | Percentual de Desconto |
| :--- | :--- |
| **A partir de R$ 300,00** | 15% |
| **Entre R$ 200,00 e R$ 299,99** | 10% |
| **Abaixo de R$ 200,00** | 5% |
